# Salman Saleem — portfolio

Personal portfolio site, published with GitHub Pages at
https://salmansaleem5123.github.io/portfolio/

Plain HTML, CSS and JavaScript. No build step and no framework.

| File | What it is |
| --- | --- |
| `index.html` | The main one-page portfolio |
| `certifications.html` | Certificate gallery with full-size previews |
| `assets/css/site.css` | All styles (colors and fonts are set at the top in `:root`) |
| `assets/js/site.js` | Mobile menu, section highlighting, contact form, certificate lightbox |
| `assets/img/site/` | Photos, badges, favicon, link-preview image |
| `assets/img/certs/` | Certificate images |
| `assets/Salman-Saleem-Resume.pdf` | Resume linked from the site |

The contact form posts to Formspree.

To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.
